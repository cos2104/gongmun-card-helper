# 공문서 모아보기 도우미

K-에듀파인 **문서관리카드**(WXSClient) 창들을 한 창에 모아 보고, 본문·첨부를 옆 칸에서 바로 보는 윈도 프로그램입니다. 에듀파인 공식 프로그램은 아닙니다.

만든 이: **전남온라인학교 김우주** · 의견: **k203719@ai.jne.kr**

## 하는 일

- 에듀파인에서 공문을 열면 카드가 앱 가운데 칸으로 들어옵니다. 열린 카드는 왼쪽 목록에 모입니다.
- 카드에서 첨부를 누르면 한글·엑셀 창 대신 오른쪽 칸에 바로 뜹니다.
  - 본문·hwp·hwpx: 한글(2014·NEO·2018·2020·2022·2024 등 깔린 판)이 있으면 그 창을 칸에 넣어 원문 그대로, 없으면 카드의 한글 부품으로
  - pdf: 윈도에 들어 있는 PDF 그리기로 원문 그대로
  - 워드·엑셀·파워포인트: 깔린 MS 오피스로 원문 그대로(편집은 그 프로그램 창을 옆 칸 자리에 띄움)
  - [이음오피스](https://github.com/pblsketch/openoffice/releases/latest)는 [설정 ▾] `이음오피스 쓰기`를 켰을 때만
- [편집]으로 그 자리에서 고치고, [저장]하면 카드 첨부 파일에 덮어씁니다(기안 작성 카드가 고친 첨부를 올리도록). 조회·결재 카드면 정해 둔 폴더에도 한 부 남깁니다.
- 문서번호·시행번호를 `번호(2026.10.29.)` 모양으로 복사합니다.
- 첨부를 정해 둔 폴더에 한 번에 저장합니다.
- 연속결재로 카드가 다음 문서로 넘어가면 다시 읽습니다.
- 앱을 닫으면 앱 안의 조회·결재 카드도 같이 닫습니다(기안 작성 중인 카드는 꺼내 둡니다).
- 결재·접수·발송 같은 처리는 하지 않습니다. 카드 화면 그대로 쓰시면 됩니다.

## 설치

[Releases](https://github.com/cos2104/gongmun-card-helper/releases/latest)에서 `gongmun-card-helper.exe`를 받아 아무 폴더에 두고 실행합니다(이름은 `공문서모아보기도우미.exe`로 바꿔도 됩니다).
새 판이 올라오면 위쪽에 [업데이트] 단추와 오른쪽 아래 알림이 나타나고, 누르면 알아서 바뀝니다.

필요한 것

- 윈도 10·11, K-에듀파인이 깔린 PC(.NET Framework 4.8은 윈도에 들어 있음)
- 있으면 더 좋은 것: 한글(판은 상관없음, 한글 원문 보기·편집), MS 오피스(워드·엑셀·파워포인트 보기·편집)

## 직접 빌드

```powershell
.\make_icon.ps1   # icon.ico
.\build.ps1       # 공문서모아보기도우미.exe (x86 — 카드의 한글 부품이 32비트)
```
